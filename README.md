# The Sentinels of the Rose — Website

Public website for The Sentinels of the Rose, an armored sword-combat performance group based in southwest Michigan and northern Indiana. The group performs at renaissance faires and gives presentations at libraries and schools.

- Planned stack: Astro static site, deployed to GitHub Pages by GitHub Actions.
- Future domain: sentinelsoftherose.com
- Booking email: sentinelsoftherose@gmail.com

See [PLAN.md](PLAN.md) for the full build plan and current status.

## Branches

- `main` is what gets deployed. Only merge into it when something is ready to go live.
- `dev` is where day-to-day work happens.

## Folders

- `Logo Pictures/` — logo source files (black and white-on-transparent versions, plus the Tudor rose mark).
